# Prompts das imagens — Arca Flix

Regras para TODAS as imagens:

- **Sem nenhum texto, letra, título ou logo dentro da imagem.** O site escreve os títulos por cima; texto "queimado" na arte briga com o layout.
- Deixe **espaço vazio** onde o texto vai entrar (indicado em cada prompt).
- Mesmo estilo em tudo, para o catálogo parecer uma marca só.

**Estilo base (cole no fim de cada prompt):**

> 3D animated feature film style, soft rounded characters, expressive big eyes, warm golden-hour lighting with gentle lilac and soft purple accents in the sky and shadows, cozy and joyful mood, rich but soft colors, cinematic depth of field, high detail, family friendly, no text, no letters, no words, no logo, no watermark

**Proporções:** banners 16:9 (1920×1080) · cartões verticais 4:5 (1080×1350) · capas 2:3 (1000×1500).
